NEGRAM 2.0 — GLASS EDITION

Интерфейс в стиле привычного мессенджера: список диалогов, поиск, экран переписки, нижняя навигация. Визуальный стиль — фиолетовое стекло, прозрачные панели, размытие и мягкое свечение.

Возможности исходного 0.7 сохранены: регистрация/вход на устройстве, профиль, стикеры, пузыри сообщений, темы, Premium demo, локальная переписка.

Добавлено оформление обложек: четыре готовых фона чата и загрузка собственной картинки. Фон сохраняется на этом устройстве. Фото профиля и обложка профиля также меняются в разделе Профиль.

Установка: распакуй архив и загрузи ВСЕ файлы в корень репозитория GitHub Pages, заменив старые файлы. В Settings → Pages выбери main / root.

Важно: аккаунты и сообщения пока локальные. Это не многопользовательский онлайн-мессенджер. Для реального общения между разными людьми нужен сервер, база данных и синхронизация.
