NeGram 2.0 — старый интерфейс

Внутри ZIP находятся файлы сайта. Для локального просмотра открой index.html.
Для публикации через GitHub Pages загрузи все файлы из архива в корень репозитория и включи Pages для ветки main / root.

Важно: это фронтенд-прототип. Локальные сообщения хранятся на устройстве; онлайн-доставка сообщений, аккаунты и синхронизация между устройствами ещё не реализованы. NE AI использует настроенный Cloudflare Worker.
