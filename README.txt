NEGRAM 2.0 — ORIGINAL 0.7 INTERFACE

Эта сборка сохраняет исходный интерфейс NEGRAM 0.7: экран входа и регистрации, верхнюю панель, нижнюю навигацию, профиль, стили пузырей, темы, стикеры и Premium. Новые функции добавлены отдельными разделами.

Файлы: index.html, style.css, app.js, manifest.json, sw.js, icon.svg, apple-touch-icon.png, negram-display.otf.

Установка на GitHub Pages:
1. Распакуй ZIP.
2. Загрузи ВСЕ файлы в корень репозитория negram-app, заменив старые версии.
3. В GitHub открой Settings → Pages и проверь публикацию из main / root.
4. Открой опубликованный сайт в Safari.

Важно:
- Регистрация, профиль и переписка пока локальные — данные хранятся на этом устройстве.
- NEGRAM AI обращается к настроенному Cloudflare Worker.
- Видеокружки записываются локально и добавляются в локальный чат; серверная доставка пока не подключена.
- Premium остаётся демонстрационным режимом без оплаты.
- Для регистрации нужен HTTPS.
